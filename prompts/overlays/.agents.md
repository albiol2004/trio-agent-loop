# .agents — generic agents skills tree (embedded only)

`.agents/skills/trio/SKILL.md` is the orchestrator SKILL for the generic
`~/.agents` skills tree; it has NO standalone role files in-repo (the
harness-specific role agents live in the `.claude/`, `.codex/`, and
`codex/` trees). The role protocol reaches this flavor through the
marked-region upsert of the protocol-essentials block into
`.agents/skills/trio/SKILL.md` (see the EMBEDDED table in generate.py). No
role targets.
