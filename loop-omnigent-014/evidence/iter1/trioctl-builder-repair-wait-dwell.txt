🤖 The Evaluator pass was ending on Cursor’s first completed assistant ack because `_wait_for_session` treated `idle + bound + has_assistant` as terminal with no dwell. Dedicated runners made that ack visible while the role was still working, so the driver moved on, saw an empty `VERDICT.md`, and prune deleted the live Evaluator.

The fix is two gates on the same session: idle must hold for `stable_idle` (including the assistant-ack branch; `running` still resets the timer), and Lead/Evaluator are not done until `LOG.md` / `VERDICT.md` show a post-dispatch artifact. Live dwell is 30s via `TRIO_OMNIGENT_IDLE_DWELL`; tests with `interval=0` still skip it.
